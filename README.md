# Weather Outfit App (v5)

추천 형식을 '단어:설명' 규격으로 고정하고 전국 17개 시/도를 지원하는 최신 버전입니다.

## 🌟 이번 버전의 주요 변경 사항
1. **출력 형식 규칙 강화 ('단어:설명'):**
   - 추천 결과가 반드시 `단어:설명` (예: `날씨 요약: ...`, `상의: ...`, `하의: ...`) 구조로 출력됩니다.
   - 마크다운 기호(*, #, @ 등)는 완전히 제거되었으며, 직관적인 이모티콘만 함께 사용됩니다.
2. **전국 17개 시/도 지원 및 기타 기능 유지:**
   - 광역 지자체 전체 지원, GPS 기반 현장 날씨 제보, 기온/습도/강수량/UV 지수 자동 연동 등 기존 기능 그대로 유지.

## 📁 파일 구조
- `package.json`: Vercel ESM 설정 (`"type": "module"`)
- `index.html`: 프론트엔드 (전국 17개 시/도 선택 + 현장 제보 UI)
- `api/generate.js`: 백엔드 서버리스 함수 ('단어:설명' 형식 지정 AI 추천)
- `README.md`: 프로젝트 설명 문서

## 🚀 Vercel 배포 방법
1. 압축을 해제한 파일들을 GitHub 저장소에 업로드합니다.
2. Vercel에서 저장소를 임포트(Import)합니다.
3. `GEMINI_API_KEY` 환경변수를 설정하고 배포를 진행합니다.
