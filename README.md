# Weather Outfit App (v4)

대한민국 전국 17개 시/도 전체 지원 및 깔끔한 출력 출력을 보장하는 버전입니다.

## 🌟 주요 변경 사항
1. **전국 17개 시/도 전체 반영:**
   - 서울특별시, 부산광역시, 대구광역시, 인천광역시, 광주광역시, 대전광역시, 울산광역시, 세종특별자치시, 경기도, 강원특별자치도, 충청북도, 충청남도, 전라북도특별자치도, 전라남도, 경상북도, 경상남도, 제주특별자치도 포함
2. **출력 텍스트 정돈 (*, #, @ 제거):**
   - AI 프롬프트 및 백엔드 지침을 수정하여 마크다운 특수문자(*, #, @ 등)를 모두 제거하였습니다.
   - 직관적인 이모티콘만 활용하여 텍스트를 깔끔하게 출력합니다.

## 📁 파일 구조
- `package.json`: Vercel ESM 설정 (`"type": "module"`)
- `index.html`: 프론트엔드 (전국 17개 시/도 드롭다운 + 현장 제보)
- `api/generate.js`: 백엔드 서버리스 함수 (Open-Meteo API + Gemini API)
- `README.md`: 프로젝트 설명 문서

## 🚀 배포 방법
1. 압축을 해제한 파일들을 GitHub 저장소에 업로드합니다.
2. Vercel에서 저장소를 불러옵니다.
3. 환경변수 `GEMINI_API_KEY`를 설정하고 배포합니다.
