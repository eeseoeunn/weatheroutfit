# Weather Outfit App (v6)

목적지별 제보 유무에 따른 동적 퍼센트 통계 표시 기능이 적용된 버전입니다.

## 🌟 주요 변경 및 구현 사항
1. **목적지 제보 정보 띄우기 조건부 변경:**
   - 기존처럼 상단에 무조건 제보 문구를 띄우는 대신, 목적지 드롭다운 선택 후 **해당 지역에 등록된 제보가 존재하는 경우에만** 선택창 바로 밑에 제보 안내 박스가 나타납니다.
2. **오늘 받은 제보 통계 퍼센트(%) 요약:**
   - 선택된 지역의 제보 데이터 개수를 집계하여 체감 온도(예: 더움 67%, 적당함 33%) 및 현장 날씨(예: 화창함 100%) 비율을 퍼센트(%)로 자동 계산해 띄워줍니다.
3. **'단어:설명' 규격 및 특수문자 제거 유지:**
   - 마크다운 특수문자(*, #, @ 등) 제거 및 `단어:설명` 형식의 깔끔한 AI 옷차림 추천 출력 유지.

## 📁 파일 구조
- `package.json`: Vercel ESM 설정 (`"type": "module"`)
- `index.html`: 프론트엔드 (목적지별 퍼센트 통계 박스 동적 출력 + 제보 수집)
- `api/generate.js`: 백엔드 서버리스 함수 (퍼센트 요약 종합 AI 분석)
- `README.md`: 프로젝트 설명 문서

## 🚀 배포 방법
1. 압축을 해제한 파일 전체를 GitHub 저장소에 업로드합니다.
2. Vercel에서 저장소를 불러옵니다.
3. `GEMINI_API_KEY` 환경변수를 설정하고 배포합니다.
